# Formato de registro de aprendizaje

Guardar en `learning-records/NNNN-<slug>.md`.

```md
# <Aprendizaje>

**Fecha:** YYYY-MM-DD

## Comprensión adquirida
<Idea no obvia y evidencia.>

## Dificultades
<Errores o confusiones observadas.>

## Próximo desafío
<Paso dentro de la zona de desarrollo próximo.>
```

Registrar aprendizaje duradero, no un log de actividad. Actualizar mediante un registro nuevo cuando cambie la comprensión.
