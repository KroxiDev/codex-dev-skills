# Formato de GLOSSARY.md

`GLOSSARY.md` es el lenguaje canónico de este workspace de enseñanza. Todas las explicaciones, ejercicios y registros de aprendizaje deben adherirse a su terminología. Construirlo es en sí mismo parte del aprendizaje: comprimir un concepto en una definición apretada es evidencia de que el usuario lo entiende.

## Estructura

```md
# Glosario de {Tema}

{Descripción de una o dos frases del tema que cubre este glosario.}

## Términos

**Hipertrofia**:
Crecimiento muscular impulsado por tensión mecánica y estrés metabólico a lo largo de sesiones de entrenamiento repetidas.
_Evitar_: Volumen, ponerse grande

**Sobrecarga progresiva**:
Aumentar sistemáticamente la demanda sobre un músculo con el tiempo — vía carga, volumen o intensidad.
_Evitar_: Apretar más, subir de nivel

**RPE (Rate of Perceived Exertion)**:
Una autoevaluación de 1–10 de lo dura que se sintió una serie, donde 10 es el fallo y 8 significa dos repeticiones en la recámara.
_Evitar_: Puntuación de esfuerzo, calificación de intensidad
```

## Reglas

- **Añadir un término solo cuando el usuario lo entienda.** El glosario es un registro de conocimiento comprimido, no un diccionario que el usuario lee para aprender. Si el usuario acaba de conocer un concepto, esperar hasta que pueda usarlo correctamente antes de promoverlo aquí.
- **Tener opinión.** Cuando existan varias palabras para el mismo concepto, elegir la mejor y listar el resto como aliases a evitar. Así es como el lenguaje se comprime.
- **Definiciones apretadas.** Una o dos frases. Definir qué ES el término, no qué hace ni cómo se hace.
- **Usar los propios términos del glosario dentro de las definiciones.** Una vez que un término está en el glosario, preferirlo en todas partes — incluso dentro de otras definiciones. Esto es lo que hace que los términos complejos sean más fáciles de captar después.
- **Agrupar bajo subencabezados** cuando emerjan clusters naturales (p. ej. `## Anatomía`, `## Programación`). Una lista plana está bien cuando los términos cohesionan.
- **Señalar las ambigüedades explícitamente.** Si un término se usa de forma laxa en el campo general, anotar la resolución: "En este workspace, 'serie' siempre significa serie efectiva — los calentamientos se registran aparte."
- **Revisar a medida que el entendimiento se profundice.** Una definición que el usuario escribió la primera semana puede estar mal la sexta. Actualizar en el sitio; no dejar entradas rancias.
