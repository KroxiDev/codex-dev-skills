# Formato de contexto

```md
# <Nombre del contexto>

<Qué es y por qué existe.>

## Lenguaje

**Pedido:**
Solicitud de compra realizada por un cliente.
_Evitar_: Compra, transacción
```

Elegir términos canónicos, definirlos en una o dos frases e incluir solo conceptos propios del dominio. Agrupar por subdominio cuando resulte natural.

Para un único contexto, usar `CONTEXT.md` en la raíz. Para varios, usar `CONTEXT-MAP.md` con enlaces a cada contexto y sus relaciones. Crear estos archivos de manera diferida y preguntar solo si no puede inferirse el contexto correcto.
