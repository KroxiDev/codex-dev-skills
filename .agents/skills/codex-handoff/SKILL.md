# Transferir a otra tarea de Codex

1. Resumir objetivo, estado, decisiones, restricciones, trabajo pendiente, validación y próximos pasos.
2. Referenciar specs, ADRs, issues, commits y diffs existentes sin duplicarlos.
3. Incluir una sección «Skills sugeridos» con invocaciones explícitas válidas de la colección.
4. Redactar secretos, credenciales y datos personales.
5. Mostrar el resumen y pedir autorización antes de crear o enviar contenido a otra tarea.
6. Tras la autorización, usar la capacidad nativa de gestión de tareas de Codex y asignar un título descriptivo.
