# Editar un artículo

1. Dividir el artículo según sus headings e identificar el punto principal de cada sección. Tratar la información como un grafo dirigido acíclico: ordenar secciones y contenido para que cada idea aparezca después de sus dependencias. Mostrar la estructura y confirmarla con el usuario.
2. Reescribir cada sección, en orden, para mejorar claridad, coherencia y flow. Mantener cada párrafo en un máximo de 240 caracteres.
